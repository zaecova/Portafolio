# Portafolio de Zara Ester Córdova Vásquez

Sitio estático en español. No requiere instalar dependencias ni ejecutar una compilación.

## Publicar en GitHub Pages

1. Crea un repositorio público nuevo en GitHub.
2. Sube **el contenido de esta carpeta** (`index.html`, `styles.css`, `script.js` y `assets/`) a la raíz del repositorio. Puedes usar «Add file → Upload files» en GitHub.
3. En el repositorio, abre **Settings → Pages**. En «Build and deployment», selecciona **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`. Guarda los cambios.
4. GitHub mostrará la dirección pública del sitio en la misma pantalla cuando se complete la publicación. Puede tardar unos minutos.

Antes de publicar, revisa el texto de la fotografía y el apartado de formación. La frase solicitada dice «Graduada en Ciberseguridad», mientras que el currículo aportado registra la maestría de Saint Leo University como estudios de 2023–2026. Si cambió el estado del título, ajusta la sección de formación para que ambos datos coincidan.

Para cambiar el correo, edita la dirección en la sección `#contacto` de `index.html`. Para reemplazar la foto, usa el mismo nombre de archivo en `assets/`.
